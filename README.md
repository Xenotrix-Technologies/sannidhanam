# Sannidhanam Earth Movers – Premium Website

> **Powering Projects. Moving The Earth.**  
> Official modern web application for Sannidhanam Earth Movers – heavy machinery rental, earthmoving contractors, and certified building materials supplier based in Thrissur, Kerala.

---

## 🏗️ Overview

This project is a complete, agency-grade rebuild of the Sannidhanam Earth Movers website. Designed with a bold industrial aesthetic and precision UI/UX, the application communicates heavy machinery strength, site operational reliability, and effortless customer booking.

### 🌟 Brand & Visual Identity
- **Primary Palette**: Deep Charcoal (`#171A1D`), Industrial Black (`#25292D`), Heavy Equipment Yellow (`#FFB800`), Off-White (`#F5F5F2`), Dark Grey (`#33383D`).
- **Typography**: Industrial headings in `Barlow Condensed` / `Outfit`, body copy in `Inter`.
- **Authentic Assets**: Preserves original company branding, high-res logo (`/logo.png`), verified contact numbers, and registered office address in Thrissur, Kerala.

---

## 🚜 Key Features & Structure

### 1. Home Page
- **Impact Hero**: Large machinery background, bold typography, instant call-to-action, 7-day operational badge, and live metric pills.
- **Company Introduction**: 15+ years experience overview, core operating pillars, and field credibility.
- **Services Overview**: Complete service catalog cards with applications, advantages, and direct WhatsApp enquiry buttons.
- **Machinery Fleet Showcase**: Filterable showcase of JCB 3DX, Hitachi Mini/Heavy Excavators, Bulldozers, Rock Breakers, and Tippers with real technical specifications.
- **Quarry Materials Strip**: Direct site delivery for M-Sand, P-Sand, 20mm/40mm Coarse Aggregates, Boulder Rocks, and Slurry with 1, 2, 3, or 5-unit capacity options.
- **Why Choose Us**: 6 core advantages (Rapid Mobilization, 7 Days a Week, Maintained Fleet, Certified Operators, Integrated Materials, Direct Pricing).
- **Projects / Site Gallery**: Completed site works across Thrissur and Central Kerala with category filtering and interactive image preview.
- **Company Statistics**: Counter achievements (15+ Years, 1,250+ Sites, 22+ Machines, 7 Days a Week).
- **Testimonials**: Reviews from civil contractors, site engineers, and private builders.
- **CTA Banner**: High-conversion booking callout with direct hotline phone links and WhatsApp integration.

### 2. Dedicated Pages
- **About Page** (`#/about`): Company history, mission, vision, engineering discipline, preventative maintenance standards, and workforce safety compliance.
- **Services Page** (`#/services`): Full service directory with in-depth technical workflows, applications, and interactive materials delivery selector.
- **Machinery Page** (`#/machinery`): Complete fleet catalogue with category filters, detailed specs grid (Weight, HP, Dig Depth, Bucket/Blade Capacity), hire modes (Hourly, Shift, Weekly, Contract), and individual WhatsApp booking.
- **Projects / Gallery Page** (`#/projects`): High-resolution site gallery with category filtering and full-screen lightbox modal.
- **Contact Page** (`#/contact`): Direct hotlines, WhatsApp quick desk, office address, opening hours, Google Maps integration, and comprehensive online enquiry form.

### 3. Conversion Optimization
- **Floating WhatsApp Quick Button**: One-click WhatsApp booking with pre-filled enquiry text.
- **Click-to-Call Hotlines**: Quick call links for mobile and desktop (`+91 9496697937` & `+91 9846882822`).
- **Interactive "Get Free Quote" Modal**: Step-by-step equipment and service selector accessible from any page.
- **Context-Aware Prefills**: WhatsApp links automatically embed the selected machine or service name.

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- **Bundler & Tooling**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3.4](https://tailwindcss.com/) + PostCSS + Autoprefixer
- **Icons**: [Lucide React](https://lucide.dev/)
- **Typography**: Google Fonts (Barlow Condensed, Outfit, Inter)

## 🚀 Getting Started

### Development
```bash
# Start Vite development server
npm run dev
```

### Production Build
```bash
# Type-check and build production bundle
npm run build

# Preview production build locally
npm run preview
```
